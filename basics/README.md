# basics

- 0-current_working_directory: prints the absolute path of the current working directory.
- 1-listit: lists the contents of the current directory.
- 2-bring_me_home: changes the working directory to the home directory.
- 3-listfiles: lists the current directory contents in long format.
- 4-listmorefiles: lists all files, including hidden ones, in long format.
- 5-listfilesdigitonly: lists all files in long format with numeric user and group IDs.
- 6-firstdirectory: creates the directory my_first_directory in /tmp.
- 7-movethatfile: moves the file betty from /tmp to /tmp/my_first_directory.
- 8-firstdelete: deletes the file betty from /tmp/my_first_directory.
- 9-firstdirdeletion: deletes the directory my_first_directory from /tmp.
- 10-back: changes the working directory to the previous one.
- 11-lists: lists all files in long format in the current directory, the parent directory and /boot.
- 12-file_type: prints the type of the file /tmp/iamafile.
- 13-symbolic_link: creates a symbolic link named __ls__ to /bin/ls in the current directory.
- 14-copy_html: copies HTML files to the parent directory only if they are new or newer.
- 15-lets_move: moves all files starting with an uppercase letter to /tmp/u.
